╔══════════════════════════════════════════════════════════════════════════════╗
║ 🎯 PRIMER FLUJO DE PRUEBA                                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

   1. REGISTRATE
      POST /api/auth/registro
      {
        "email": "tu@email.com",
        "password": "MiContra123!",
        "passwordConfirmacion": "MiContra123!",
        "nombre": "Tu Nombre",
        "apellido": "Tu Apellido"
      }

   2. GUARDA EL ACCESS TOKEN
      Copia el "accessToken" de la respuesta

   3. AUTORIZA EN SWAGGER
      • Clic en botón "Authorize" (candado arriba)
      • Pega: Bearer {accessToken}
      • Clic en "Authorize"

   4. OBTÉN TU PERFIL
      GET /api/usuarios/perfil
      (¡Ya no necesitas pegar el token en cada request!)

   5. EDITA TU PERFIL
      PUT /api/usuarios/perfil
      {
        "nombre": "Nuevo Nombre",
        "apellido": "Nuevo Apellido"
      }

   6. REFRESCA EL TOKEN
      POST /api/auth/refresh
      {
        "refreshToken": "{el-refreshToken-del-paso-1}"
      }

   7. CAMBIA LA CONTRASEÑA
      PUT /api/usuarios/cambiar-contrasena
      {
        "contrasenaActual": "MiContra123!",
        "nuevaContrasena": "NuevaContra456!",
        "confirmacion": "NuevaContra456!"
      }

   8. HAGA LOGOUT
      POST /api/usuarios/logout
      {
        "refreshToken": "{refreshToken}"
      }
